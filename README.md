# DropName

DropName (BizDetails AI) is a web platform for enriching company data and mapping them to domains using AI.

## Structure

- `frontend/` - Next.js application with React and TailwindCSS
- `backend/` - FastAPI service providing enrichment endpoints

## Getting Started

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
